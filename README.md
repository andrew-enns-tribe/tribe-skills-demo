# Tribe Skills Demo Marketplace

Demo marketplace repository for the Skills MCP generated by the MCP Factory.

Repository conventions:

- Promoted plugins live on `main`.
- Submitted but unvetted plugins live on `sandbox`.
- Each plugin lives under `plugins/<plugin-name>/`.
- Each plugin contains a `.claude-plugin/plugin.json` manifest plus one or more `skills/`, `commands/`, or `agents/` entries.

- `beautiful-mermaid`
- `slides-storyliner`
